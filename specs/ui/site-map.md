## 核心页面流程

### 员工咨询流程

```
员工登录 → 首页（HR 助手对话框）
         │
         ├─ 输入问题 → AI 回答 → 满意/不满意反馈
         │
         ├─ 点击常见问题 → 快速问答
         │
         └─ 转人工 → HR 客服接入
```

### HR 管理流程

```
HR 登录 → 管理后台
        │
        ├─ 知识库管理 → 上传文档 → 解析 → 生效
        │
        ├─ 问答日志 → 筛选/搜索 → 导出
        │
        └─ 数据分析 → 查看报表 → 下载
```
