## 3. 组件规格

### 3.1 顶部栏

| 元素 | 说明 | 交互 |
|------|------|------|
| Logo + 产品名 | HR Co-Pilot OS | 点击返回首页 |
| 用户头像 + 姓名 | 当前登录用户 | 点击下拉菜单（个人中心/退出） |

### 3.2 对话区

| 元素 | 说明 | 交互 |
|------|------|------|
| AI 消息气泡 | 左侧，灰色背景 | 可点击"有用/无用"反馈 |
| 用户消息气泡 | 右侧，蓝色背景 | - |
| 常见问题快捷入口 | 顶部，可横向滚动 | 点击快速填充输入框 |
| 转人工按钮 | 输入区右侧 | 点击转接 HR 客服 |

### 3.3 输入区

| 元素 | 说明 | 交互 |
|------|------|------|
| 文本输入框 | 支持多行输入 | 输入问题 |
| 发送按钮 | ➤ 图标 | 点击发送/回车发送 |
| 附件按钮 | 📎 图标 | 上传图片/文件（如报销凭证） |
| 语音按钮 | 🔊 图标 | 语音输入（后续迭代） |

---

## 4. 交互规格

### 4.1 发送消息

```
用户输入问题 → 点击发送/按回车
            ↓
显示"思考中..."动画（约 1-2 秒）
            ↓
AI 回答显示（流式输出，逐字显示）
            ↓
显示"有用/无用"反馈按钮
```

### 4.2 快捷入口

```
点击常见问题 → 自动填充输入框 → 自动发送
```

### 4.3 转人工

```
点击"转人工" → 确认弹窗 → 连接 HR 客服 → 显示客服头像和昵称
```

## 6. 状态说明

| 状态 | 说明 | UI 表现 |
|------|------|--------|
| 加载中 | AI 正在回答 | 显示"思考中..."动画 |
| 网络错误 | 请求失败 | 显示"网络异常，请重试" |

| 客服接入 | 客服已接入 | 显示客服头像和欢迎语 |
