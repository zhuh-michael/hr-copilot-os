# US-003：行为规格

---

## 行为 1：错别字容错

```gherkin
Given 员工已登录
When 员工输入以下任一问题：
  | 输入 |
  | "年假怎摸算" |
  | "年假怎么蒜" |
  | "年架怎么算" |
Then AI 都能识别为员工想问"年假怎么算"
  And AI 正确回答年假计算规则
```

---

## 行为 2：不完整提问

```gherkin
Given 员工已登录
When 员工仅输入关键词：
  | 输入 |
  | "年假" |
  | "社保" |
  | "报销" |
Then AI 理解员工想了解该主题的政策
  And AI 回答该主题的常见问题列表
  And AI 提供"查看更多"选项
```

---

## 行为 3：口语化表达

```gherkin
Given 员工已登录
When 员工输入以下任一口语化问题：
  | 输入 |
  | "请病假扣钱吗" |
  | "迟到扣不扣钱" |
  | "加班给不给钱" |
Then AI 理解员工在问薪资相关政策
  And AI 正确回答对应政策
```

---

## 行为 4：澄清确认

```gherkin
Given 员工已登录
When 员工提问过于模糊（如"那个怎么办"）
Then AI 无法确定具体问题时
  And AI 回复"请问您具体想了解什么呢？比如年假、社保、报销等"
```
