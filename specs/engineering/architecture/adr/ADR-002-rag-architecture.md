# ADR-002：选择 RAG 架构作为 AI 方案

**日期：** 2026-02-27  
**状态：** ✅ 已确认

---

## 1. 背景

需要为 HR 问答机器人选择 AI 技术方案，确保回答准确、可解释、可追溯。

---

## 2. 决策驱动因素

| 因素 | 说明 |
|------|------|
| **准确性** | 回答必须基于企业制度，不能胡编 |
| **可解释性** | 需要说明答案来源 |
| **可追溯** | 答案需要可追溯到具体制度文档 |
| **更新及时** | 制度更新后，AI 回答需同步更新 |

---

## 3. 选项对比

| 方案 | 优点 | 缺点 | 评分 |
|------|------|------|------|
| **RAG（检索增强生成）** | 基于知识库、可解释、可追溯 | 需要维护知识库 | ⭐⭐⭐⭐⭐ |
| 纯 LLM（微调） | 回答流畅 | 可能编造、不可追溯 | ⭐⭐⭐ |
| 纯检索 | 准确、可追溯 | 回答生硬、不灵活 | ⭐⭐⭐⭐ |

---

## 4. 决策

**选择：RAG（检索增强生成）架构**

**流程：**
```
用户提问 → 向量化 → 检索相似文档片段 → LLM 基于文档生成回答 → 返回
```

**理由：**
1. 回答基于企业制度，准确性高
2. 可以提供来源链接，可解释性强
3. 制度更新后，重新向量化即可，无需重新训练
4. LangChain 提供完善的 RAG 流程支持

---

## 5. 影响

### 5.1 正面影响
- 回答准确，减少胡编乱造
- 员工信任度高（有来源）
- 知识库更新方便

### 5.2 负面影响
- 需要维护向量数据库
- 检索速度影响响应时间（需优化）

---

## 6. 遵循决策

- 使用 LangChain RAG 流程
- 使用 Chroma/Milvus 作为向量数据库
- 回答中附带来源文档链接
