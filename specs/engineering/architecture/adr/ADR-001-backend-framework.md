# ADR-001：选择 Node.js + Express 作为后端框架

**日期：** 2026-02-27  
**状态：** ✅ 已确认

---

## 1. 背景

需要为 HR Co-Pilot OS 选择后端框架，支撑 F-001 智能问答机器人功能。

---

## 2. 决策驱动因素

| 因素 | 说明 |
|------|------|
| **开发效率** | 团队熟悉 JavaScript/TypeScript |
| **AI 生态** | 需要良好的 AI/LLM 库支持 |
| **并发能力** | 支持高并发问答请求 |
| **部署简单** | 易于 Docker 容器化 |

---

## 3. 选项对比

| 框架 | 优点 | 缺点 | 评分 |
|------|------|------|------|
| **Node.js + Express** | 轻量、生态好、LangChain 支持 | 单线程 | ⭐⭐⭐⭐⭐ |
| Python + FastAPI | AI 生态最强 | 团队不熟悉 | ⭐⭐⭐⭐ |
| Java + Spring Boot | 企业级、稳定 | 笨重、开发慢 | ⭐⭐⭐ |
| Go + Gin | 性能最好 | AI 生态弱 | ⭐⭐⭐ |

---

## 4. 决策

**选择：Node.js + Express**

**理由：**
1. 团队技术栈匹配（前端也是 Vue/TS）
2. LangChain 有完善的 Node.js 版本
3. 轻量级，适合快速迭代
4. 并发能力足够（1000+ QPS）

---

## 5. 影响

### 5.1 正面影响
- 前后端统一语言（TypeScript）
- 开发效率高
- 代码复用（工具函数等）

### 5.2 负面影响
- CPU 密集型任务性能一般（但 AI 调用是 IO 密集型）
- 需要处理单线程问题（用 cluster 模块）

---

## 6. 遵循决策

- 后端代码使用 TypeScript
- 使用 Express 作为 Web 框架
- 使用 LangChain Node.js 版本

---
